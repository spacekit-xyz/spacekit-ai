# Security policy

Report suspected vulnerabilities through this repository's private security
reporting channel. Do not open public issues containing exploit details,
credentials, private datasets, model artifacts, or user conversations.

Include the affected revision and package, enabled features, reproduction,
impact, and known mitigations.

SpaceKit AI is research software. Tests and benchmark results do not constitute
a security, safety, privacy, or production-readiness certification.

Never commit secrets, populated environment files, licensed corpora,
checkpoints, generated brains, evaluation ledgers containing private data, or
production inference records. If a credential enters the working tree or Git
history, rotate it; deletion alone is insufficient.
