# Security policy

Report vulnerabilities privately through the repository's security-reporting
channel. Do not include exploit details, credentials, private datasets, model
artifacts, or user conversations in public issues.

Include the revision, enabled features, reproduction, impact, and mitigation.

Growformer LLM is research software. It is not a safety-rated language model,
and evaluation results do not establish production security or output
reliability.

Never commit secrets, populated environment files, licensed corpora,
checkpoints, tokenized datasets, generated result ledgers, or production chat
logs. Rotate any credential that enters source or Git history.
