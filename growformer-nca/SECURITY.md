# Security policy

Report vulnerabilities privately through the repository's security-reporting
channel. Include the revision, reproduction, impact, and mitigation; do not
publish exploit details before coordinated disclosure.

SpaceKit NCA is experimental research software. Passing numerical tests does
not establish adversarial robustness, model safety, or production suitability.

Never commit credentials, private datasets, checkpoints, generated model
output, or production user data. Rotate any credential that enters Git history.
