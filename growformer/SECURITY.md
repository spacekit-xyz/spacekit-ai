# Security policy

Do not open public issues containing vulnerabilities, credentials, private
datasets, model artifacts, or exploit details. Use the repository's private
security-reporting channel. If none is configured, contact the maintainers and
request a secure channel before disclosing details.

Include the affected revision, feature set, reproduction steps, impact, and
known mitigations.

Growformer is research software. Published benchmarks and passing tests do not
constitute a security, safety, privacy, or suitability certification.

Never commit API keys, private keys, populated environment files, user data,
licensed corpora, checkpoints, generated brains, or production inference
records. If a secret is committed, rotate it; deletion alone is insufficient.
