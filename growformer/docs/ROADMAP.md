# Growformer 2026 Roadmap

**Status:** Core architecture, language pipeline (M1–M6), group-theoretic generation, **OCEAN personality conditioning**, **Conversation REPL**, **two-level lattice hierarchy** (E8 + Leech), and **quantum group composition U_q(E8)** are complete. **Algebraic codebook** reduces prediction from 768–1920 raw bits to 7–120 algebraic bits (10–100× reduction). **Syntax-aware codebook** auto-fixes keywords/structure for code groups. **Prototype-gated slot-only generation** handles archetype selection via embedding similarity. **Hopf composition table** with **compatibility-scored transitions** enables emergent pattern composition. **VirtualGroup generation** (Levels 1–3: competitive multi-head, cross-group composition, episodic caching). **Understanding Layer** classifies semantic intents (79 topics, 8 verbs) via **MicroBrain** wrappers around NeuralEnvironment. **MetaBrain** coordinator learns to weight/combine micro-brain outputs; global **ArchetypeBrain** (InfraciliaryLattice/Paramecium, 331 programs) handles cross-group archetype selection. **Clifford Algebra Cl(8,0)** rotors provide geometric conditioning via 28-parameter bivector rotations. **Two-Phase Training** (Memorize → Consolidate) achieves 38% faster convergence. **Per-group low-rank adapters** (rank=8, 768d→128d, SPSA-trained). **MetaCognition** (reflective quality gate: generate→reflect→decide loop with graceful degradation) and **System 2 Reasoning** (deliberate multi-step chaining with working memory, variable-length StepOperator, transfer rotors) are implemented and validated. Next: Continuum (online learning).

## Current focus: Continuum

| Item | Description |
|------|-------------|
| **Continuum** | Online learning with feedback-driven training. See `docs/CONTINUUM.md`. |
| **Continuum Foundation (done)** | Multi-timescale `BehavioralProgram` data model inspired by Paramecium cell biology. Three timescales: **persistent** (quality_score, reliability — gene expression), **session-scoped** (session_drift, session_hits — post-translational), **volatile** (activation_level, refractory — ionic/membrane). Retrieval bias modulates scoring via quality × reliability × refractory_suppression × activation_decay. Session lifecycle: `begin_session` → per-turn `decay_activations` → `consolidate_session`. MetaCognition feedback wired to `apply_feedback` (Accept → positive, Degrade → negative). `effective_centroid()` applies session drift for in-context adaptation without modifying persistent centroids. |
| **Continuum Online Learning (done)** | Full two-layer feedback pipeline: external feedback (Accept/Reject/Correct) flows to both neural network path (LearnedRouter + GroupGenEnv training steps) and Paramecium lattice path (quality/reliability updates, correction injection). `inject_correction` degrades wrong programs and spawns/reinforces correct ones in the lattice. `TurnContext` carries `effective_gidx` + `program_idx` for precise feedback targeting. `ContinuumConfig` provides configurable checkpoint_interval, min_consolidation_hits, rate_limit_per_minute, checkpoint_path. Session consolidation at conversation reset commits drift to persistent centroids for well-used positive programs. |
| **Emergent Personality (done)** | OCEAN personality drifts from feedback: Accept → lower neuroticism, higher agreeableness (the system learns the user rewards engagement). Reject → higher conscientiousness + neuroticism (be more precise, more cautious). Correct with longer text → higher extraversion (user wants detail); shorter correction → lower extraversion (wants conciseness). Drift rate α=0.02, all dimensions clamped [0,1]. Personality serialized to JSON alongside brain checkpoint for persistence across restarts. |
| **Conversational Framing (done)** | Personality-aware prefix layer in `converse()` adds natural conversational markers. Warmth threshold = `(agreeableness + extraversion) / 2`. First-turn openers: "Let me break that down." (explain/what), "Here's how." (how-to), "Of course." (help requests), "Here's an approach." (design/build). Continuation turns: "Building on that —" (and/also), "Good point." (but/however), "Here's the reasoning:" (why). Terse personalities (engineer, analyst) skip framing entirely. Skips identity, degradation, and tool-call responses. 276 tests, 0 failures. |
| **SpaceTime Gradient Memory (done)** | Test-time optimization of memory tokens in Cl(1,7) SpaceTime Algebra. Instead of retrieving a single stored program, STGM initializes memory from k-nearest programs and runs SPSA gradient descent to compose a novel representation. **Multi-objective loss:** relevance (band coherence with query, weight 0.55), composition (inter-source coherence, weight 0.30), diversity (attention entropy, weight 0.15). **Cognitive control:** conflict monitoring escalates optimization steps (2×) when initial coherence < threshold; early stopping when coherence target reached. **Hierarchical decode:** sentence-level interleaving with bigram novelty scoring prevents redundancy. **Dual optimization:** both STA multivector components and attention weights over source programs are optimized jointly via Rademacher SPSA. Wired into IndexedGenEnv generation pipeline between codebook path and Hopf composition fallback. |
| **Predictive Coding (done)** | STA band-decomposed error signals replace the crude MetaCognition adjustment. Decomposes prediction error across all 9 Cl(1,7) grades: δ (scalar magnitude), θ (semantic direction), α/β (relational structure), γ (compositional patterns). Per-grade learning rates: grade 0 = 0.02 (gentle), grade 2 = 0.12 (strong structural correction), grade 3 = 0.15 (strong compositional). Two error sources: **forward model error** (conditioning ≠ response, weight 0.6) and **goal alignment error** (response ≠ query, weight 0.4). Early stopping on coherence target + stall detection. Wired into MetaCognition retry loop in `service.rs`. |
| **Differentiable Slot Optimization (done)** | `soft_decode_distribution(bits, num_options, temperature)` returns temperature-scaled softmax probabilities over slot options (vs hard argmax). `optimize_slot_bits` runs SPSA gradient ascent on slot bit values to maximize a quality scoring function. Wired into the codebook decode path: when field-inhibited, slot bits are SPSA-optimized (6 steps, lr=0.08) before decode, scoring by token overlap with nearest programs weighted by conditioning cosine similarity. |
| **Schema Abstraction (done)** | Extracts reusable templates from program patterns via token-level Jaccard clustering (threshold 0.35, min support 2). **Fixed positions** (≥80% agreement across programs) become template constants. **Variable positions** become typed slots with candidate token lists and frequency counts. `fill_schema` populates slots using conditioning-driven scoring. `build_schemas` runs automatically on `IndexedGenEnv` construction. Schemas tried before STGM in the generation cascade for fast template-based generation. 299 tests, 0 failures. |
| **Chunk-level Continuous Codec (done)** | CDMA spread-spectrum text autoencoder encodes K-token chunks (K=8) into Cl(1,7) multivectors (256d) with **100% reconstruction accuracy** at chunk level. Uses Walsh-Hadamard position codes (mutually orthogonal ±1 spreading) and parallel interference cancellation (PIC) for decoding — no neural networks. Generation predicts the next **vector** (representing K tokens) instead of the next **token**, reducing autoregressive steps by K×. `ChunkCodec` builds deterministic token embeddings on S^255 via Box-Muller+SplitMix64. `ChunkSequence` represents text as a trajectory of chunk vectors with centroid-based similarity. Trajectory composition via weighted blending and rotor extrapolation for next-chunk prediction. Library-based prediction finds the most similar stored trajectory prefix and returns its continuation. Slerp interpolation between chunk vectors for smooth semantic blending. Wired into `IndexedGenEnv` as the first generation path (before schemas/codebook). 314 tests, 0 failures. |
| **Multi-turn Conversation (done)** | Anaphora resolution maps pronouns ("that", "it", "this") to previous turn's parsed subject for correct multi-turn routing. Dual encoding separates intent parsing (raw user message) from generation conditioning (context-augmented prompt). Broad query cross-group search finds the most relevant group by topic name overlap instead of blindly trusting the classifier. Tool registry "what is" false-positive trigger removed from calculator. |
| **Training Objectives: RTD + Salient Span Masking (done)** | Three training games that improve embedding discriminability for Paramecium lattice retrieval — no neural networks, pure data/lattice augmentation. **Salient Span Masking:** Extracts 567 domain keywords from `knowledge_graph.toml` as a saliency lexicon. During training, preferentially masks salient tokens in expected responses, creating augmented (text, masked_response) pairs that force the model to build stronger representations for distinguishing terms (stack vs quicksort, derivative vs differential equation). **RTD (Replaced Token Detection):** Replaces salient tokens with random dictionary alternatives at higher rates than non-salient tokens. Corrupted embeddings serve as hard negatives during `develop_with_negatives()`, pushing program centroids away from confusable inputs. **Contrastive Development:** After one-pass lattice indexing, runs a contrastive refinement pass that pushes apart program centroids from different topics when cosine similarity exceeds margin (0.92). Combined with BM25 re-ranking and intent prefix layer for within-topic precision. 318 tests, 0 failures. |
| **Topic-aware ChunkCodec Generation (done)** | Promoted `ChunkCodec` from artifact-repair fallback to active topic-aware generation path. New `generate_continuous_for_topic()` composes trajectory blends from programs within a specific topic sub-lattice (not the global lattice), combining topic routing precision with continuous compositional generation. Positioned in the generation cascade after STGM but before Hopf composition, providing trajectory-based output when single-program retrieval confidence is insufficient. |
| **Retrieval Precision: BM25 + Intent Prefix (done)** | Two-stage retrieval within topic sub-lattices: (1) initial vector recall by cosine similarity, (2) BM25 re-ranking using query subject keywords as terms against decoded program text. Normalized BM25 score blended with cosine (λ=0.35). Intent prefix layer adds score modifiers based on query action: "implement"/"code"/"write" boosts code-bearing programs (+0.08), "explain"/"define"/"describe" boosts prose programs (+0.05). Conservative cross-group redirect prevents over-eager group switching. |

## Completed (no further work required for "done")

- **Phases 1–3:** Digital Bacterium, Continual Learner (frozen flag), Mirror Dimension, LearnedRouter, Composition + Episodic, Split MNIST (97.3% avg, 0% forgetting).
- **M1–M6:** Language embedding, routing validation, intent-to-action, controlled generation, M5 continual language learning (7-domain retention), M6 dual agent modes (ContextFile / MicroBrain), SLO and acceptance report.
- **Generation redesign:** Character-level autoregressive → spectral DCT exploration → dictionary + binary token prediction → **algebraic codebook** (group-theoretic factorization). Single `train_tick` per sample. Gray code + Hamming ECC + nearest-neighbor soft decode (raw binary fallback). Algebraic mode: archetype clustering + slot extraction, 10–100× dimension reduction. Per-group `GroupGenEnv` with structurally isolated `NeuralEnvironment` (no shared MLPs).
- **Syntax-aware codebook:** `build_syntax_aware` classifies tokens by syntax role (keyword, structure, operator, literal, identifier). Keywords and structural punctuation auto-fixed; only identifiers/literals become slots. 2.4× additional output dimension reduction for code. Python, Rust, JavaScript/TypeScript keywords supported.
- **Prototype-gated slot-only generation:** Archetype selection via cosine similarity to stored prototype embeddings (centroids of training embeddings per cluster). Network predicts only slot values, not archetype bits. Exposes confidence metric for OOD detection.
- **Hopf composition table:** `HopfCompositionTable` decomposes archetypes into positional fragments, builds per-fragment prototypes and **compatibility-scored transitions** (cosine similarity between archetype prototypes replaces same-archetype bonus), and uses beam search (width=3) to compose fragments from multiple archetypes. Confidence-gated: activates when prototype confidence < 0.9. OCEAN personality modulates beam diversity.
- **VirtualGroup generation (Levels 1–3) with quantum composition:** Competitive multi-head inference with E8 contribution vectors, **quantum group composition U_q(E8)** for non-commutative multi-group blending (R-matrix braiding, input-dependent deformation parameter q, leader/follower ordering), episodic memory caching. Output coherence gate (geometric confidence × bit decisiveness) prevents confident-but-wrong archetype bypass. `--retrain-gen <N>` flag for targeted single-group retraining without full brain rebuild.
- **OCEAN personality conditioning:** `OceanProfile` with presets (assistant, creative, engineer, analyst). Conditions generation vector (last 5 dims), modulates Hopf beam scoring (openness → cross-archetype diversity), modulates EMA alpha (extraversion → faster adaptation, conscientiousness → more memory).
- **Conversation REPL:** Multi-turn `converse()` with EMA state accumulation, context-augmented encoding (3-turn sliding window), turn history (20 turns), personality switching, agent identity. Commands: `/personality`, `/ocean`, `/reset`, `/history`, `/single`, `/status`.
- **Agent identity:** "who are you" interception with configurable name/creator. Defaults: Growformer by swtch.ai.
- **Pattern composition training data:** 18 new entries covering compositional architectural patterns (microservices, CQRS, hexagonal), pattern pair compositions (Observer+EventDriven, Proxy+CircuitBreaker, Strategy+Factory), UI patterns (MVC+Observer, StateMachine+ValidationChain), and identity responses.
- **Two-level lattice hierarchy:** E8 (8d, local) for archetype selection and Hopf transition scoring; Leech lattice (24d, global) for project-level spatial indexing via `ProjectModel`. E8: kissing 240, O(8) decode, Extended Hamming [8,4,4]. Leech: kissing 196,560, 3×E8 + Golay [24,12,8] construction, 3-bit correction. `ProjectModel` uses a **hybrid embedding pipeline** (structural + semantic + relational + git + test + pattern) with `CodeAnalyzer` (8 languages) and `GitHistory` for edit correlation; auto-indexes sub-entities from declarations; nearest-neighbor queries condition generation on codebase context. REPL: `/index <path>` (auto-loads git when `.git` present), `/project [file]`. See Whitepaper §5.5.
- **Engram consolidation + priority replay:** Synaptic-level memory protection (consolidation score, reduced LR, pruning immunity) and worst-15% replay after epoch 50.
- **Structural interpretability + AI safety:** Bounded output space (codebook-constrained), prompt injection resistance, frozen deterministic inference, auditable decision trails. Safety is architectural, not a learned preference. Whitepaper §5.6.
- **Infrastructure:** Multiple brains (load/serve by name), WASM library, growformer-node HTTP API, checkpoint save/load, `deploy-linux.sh` + `build-linux.sh` for server deployment. CLI split: `growformer` (production train+infer), `growformer-demos` (benchmarks/evals). Auto-configuration (`--auto`): data profiler + parameter derivation + convergence monitor with early stopping.
- **Understanding Layer + MetaBrain:** Semantic intent classification via `MicroBrain` wrappers (NeuralEnvironment). Topic brain (79 classes, 48.7% accuracy), verb brain (8 classes, 95.4% accuracy), action brain (5 classes). `MetaBrain` coordinator (NeuralEnvironment) learns to weight/combine micro-brain outputs into a unified 192d conditioning signal. Global `ArchetypeBrain` (InfraciliaryLattice/Paramecium, 331 programs across 4 groups) handles cross-group archetype selection and multi-archetype composition via trichocyst volley. Replaces hand-rolled SmallMlp classifiers and static cosine similarity throughout. All frozen after training.
- **Clifford Algebra Cl(8,0):** Per-group `GroupRotor` with 28 bivector parameters (one per e_i ∧ e_j). Applies geometric rotation of conditioning vectors via sandwich product R x R†. SPSA-trained alongside per-group adapters during generation training. Structural fingerprinting via grade-2 bivector components; structural similarity via cosine on bivectors.
- **Two-Phase Training (Memorize → Consolidate):** Phase 1 imprints data at maximum speed: lr=0.25, full k-WTA (all neurons fire), no dropout, no weight/bias decay, pruning disabled, 3 epochs. Phase 2 restores competitive learning and regularization to refine into durable engram traces: lr=0.05, k=128/512, dropout=0.05, pruning + engram consolidation enabled, 1000+ epochs with early stopping. Measured 38% faster convergence (0.288 vs 0.464 loss after 5 steps).
- **Per-group low-rank adapters:** Rank-8 projection matrices per group (768d → rank 8 → 128d). SPSA-trained during generation training (2 evaluations per step instead of dim-many). 28,672 total adapter parameters across 4 groups.
- **Expanded training data (~1,650 samples, 14 groups):** 16+ JSONL files covering support, architectural patterns, design patterns, general knowledge, math reasoning, coding (Python/Rust/JavaScript), conversation, adversarial, paraphrases, multi-turn, identity compositions, pattern compositions, information theory, Rust structures, coding general, and reasoning blends. Training validation: 16/17 cross-group prompts correct (94%). Added specific intents for LRU cache, lifetime patterns, async patterns, Python debugging, physics, and CS fundamentals.
- **Training validation + cross-group topic search:** Comprehensive inference audit across all 16 training files. Cross-group topic search redirects queries when `infer_operation_topic` identifies a topic that exists in a different group than the classifier selected. QueryIntent system parses prompts into structured action+subject pairs. Neural coherence analysis via Cl(1,7) STA band decomposition measures synchrony for multi-topic summaries. Tokenization artifact filter prevents garbled text from reaching output in both summary and single-program paths.
- **MetaCognition (Reflective Inference):** Inference-time quality gate via a generate-reflect-decide loop. `MetaCognition` module (`src/metacognition.rs`) trains a Reflection Brain from (prompt, response, topic) triples extracted from all lattice programs during training (930 pairs, 124+ topic centroids). At inference, scores each candidate response on three axes: **coherence** (semantic overlap with prompt, 0.45 weight), **relevance** (distance from topic-specific reference centroid, 0.35 weight), **completeness** (response length/structure, 0.20 weight). Combined quality score checked against configurable threshold (default 0.45). On failure: retry with adjustment vector (max 2 retries), then graceful degradation emitting a structured "I don't have knowledge about this topic" message. Automatically rebuilt from brain data on `load_brain()`. Integrated into both `generation()` and `codegen()` paths.
- **System 2 Reasoning (Deliberate Inference):** Multi-step logical chaining extending the ReasoningEngine from fixed-round wave settling to variable-length deliberate reasoning. **WorkingMemory** buffer (bounded capacity, weighted eviction) maintains activated programs and partial conclusions across steps. **StepOperator** decides next action: `Retrieve` (query a related group to diversify), `Transfer` (apply Cl(1,7) transfer rotor for analogical mapping between domains), `Compose` (sentence-level interleaving of working memory entries), or `Terminate`. Engagement heuristic: triggers when primary confidence is 0.10–0.65 AND cross-domain ambiguity exceeds 0.70 (or complex topic hint detected). Termination: coherence threshold (default 0.65) on working memory OR max steps (default 6) OR stall detection (2 consecutive rounds without improvement). No backprop, no autoregressive token loop — each step is a single lattice query or rotor application.
